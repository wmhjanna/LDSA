# Code availability

Analysis code for PNSD harmonisation, LDSA calculation, Theil–Sen trends, autocorrelation-aware bootstrap inference, change-point analysis, cross-metric comparisons, random-effects synthesis, exploratory LightGBM/SHAP modelling and figure production is available in the [LDSA repository](https://github.com/wmhjanna/LDSA), [version 1.0.0](https://github.com/wmhjanna/LDSA/releases/tag/v1.0.0). The package includes installation and usage instructions, processed BCN_UB examples and reference outputs for numerical verification. Project-authored code is distributed under the MIT License; third-party materials retain their applicable terms. Reproducing the full-network analyses additionally requires the source observations and ancillary datasets described in the Data availability statement.
